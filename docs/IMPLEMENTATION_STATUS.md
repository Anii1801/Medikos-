## Defects found in the previous engine (reproduced, then fixed)
1. Natural phrasing missed ("my speech is slurred", "I can barely breathe") -> ROUTINE.
2. Negating an unrelated symptom suppressed a real one ("black stools ... no vomiting blood" -> ROUTINE).
3. Historical events treated as current (recovered stroke -> EMERGENCY).
4. **Engine failure produced `[]` in `/api/summary`, `/api/submit`, queue priority and FHIR** (false "no flags"). Now `SCREENING_UNAVAILABLE`, priority 1, and the UI says screening is unavailable.
5. Evaluation script passed the label's `red_flag_reason` to the engine (leakage in design). Measured effect on this engine: none (identical numbers with/without), so earlier results were not inflated by it.

## Measured red-flag results (synthetic dataset, NOT clinical evidence)
`05_triage_redflag/red_flag_labeled_cases.csv`: 300 rows, 19 positives (13 "ACS", 6 "stroke"), templated generator.
EMERGENCY-level: sensitivity 19/19 (95% CI 0.83–1.00; test split only 3 positives, CI 0.44–1.00), specificity 0.918, precision 0.452, 0 FN, 23 FP.
All 23 FPs: "chest tightness" + breathlessness in a "cough and breathlessness" template, triggering R01. This is the price of
detecting chest *tightness/pressure*, not just the phrase "chest pain". Not tuned to this dataset (would overfit the generator);
**clinician decision needed** on whether low-severity tightness + breathlessness should be EMERGENCY.
`evaluation_results/research_evaluation.json` (older run, Windows path) is superseded for red flags and should be regenerated.

## Not done in this session (honest gaps vs the 14-phase spec)
- Phase 3: the question policy is still the ontology's fixed ordered questionnaire with chief-complaint branching (`todo[0]`), not a learned or
  slot-ranked policy. No new `AdaptiveHistoryTakingAgent`, no baseline-vs-adaptive experiment, so **no efficiency/completeness claim is supported.**
- Phases 4/6/8/11 training and OCR/summarisation benchmarks (ROUGE/BERTScore/CER/WER, BioBERT comparison): not run.
- Hindi/code-mixed NLP unsupported. Notes: no clinical annotation set exists to measure NLP precision/recall/negation accuracy; the 29 NLP tests are hand-written behaviour checks, not a benchmark.
- Rule provenance: rules cite WHO Basic Emergency Care (2018) as recorded by the earlier session; I did not verify each rule against that document. All are marked provisional pending clinician sign-off, and the UI says so.
